この冊子の使い方

一つの言葉を「ひとことで」→「たとえると（絵）」→「SpaceClipでは」→「覚えておくこと」の順に説明しています。まず絵とたとえ話で全体をつかみ、細かいことは必要になったときに読み返してください。

言葉の関係（おおまかな地図）

「AI」がいちばん大きなくくり。ChatGPTやClaudeは、いちばん内側の「LLM」です。

知らない言葉に出会ったら

この冊子に無い言葉は、AIに聞くのがいちばんの近道です。

「〇〇という言葉を、建築設計事務所で働く人向けに、たとえ話を1つ入れて3行で説明して」

答えに出てきた固有名詞や数字は、公式の説明で確かめましょう。

第1章AIの基本まずは「何がどれの仲間か」をつかむ
01AI（人工知能）エーアイ / Artificial Intelligence
ひとことで

人の知的な作業（見分ける・読む・判断する など）を、コンピューターで行う技術の総称。

たとえると

「乗り物」のような大きなくくり。自転車も電車も乗り物であるように、生成AIも機械学習も、AIの仲間です。

SpaceClipでは
スマホの写真アプリが「建物」「書類」を自動で分けるのも、Claudeが法チェックを手伝うのも、どちらもAIです。
覚えておくこと
「AI」は広い呼び名。話しているのがどのAIか（生成AIなのか、ほかか）を意識すると、話が通じやすくなります。
02機械学習きかいがくしゅう / Machine Learning
ひとことで

人がルールを1つずつ書くのではなく、たくさんのデータからパターンを見つけさせる方法。

たとえると

ベテラン職人の「勘」。何百もの現場を見てきた人は、理由をうまく説明できなくても「この壁は傷みやすい」と分かります。AIはそれをデータで身につけます。

SpaceClipでは
迷惑メールの自動振り分けは、機械学習の代表例です。
覚えておくこと
データに無いことは苦手です。データの量と質で、賢さが決まります。
03ディープラーニング深層学習 / Deep Learning
ひとことで

何層もの計算を重ねて、複雑な特徴を自動で見つける機械学習の一種。今のAIの中心となる技術。

たとえると

流れ作業の検査。1段目は「線」、2段目は「形」、3段目は「窓や屋根」…と段を重ねるほど、細かな特徴から全体を見分けられるようになります。

SpaceClipでは
スキャンした書類の文字の読み取り、写真の自動補正、文字起こしなど。
覚えておくこと
「深層学習」とも呼びます。どう判断したのか、中身は人にも見えにくい技術です。
04生成AIせいせいエーアイ / Generative AI
ひとことで

文章・画像・音声などを、新しく作り出すAI。

たとえると

仕事の早い「新人の書記さん」。頼めばすぐに下書きを作ってくれますが、中身の確認は先輩（人）の仕事です。

SpaceClipでは
打合せの録音から議事録の下書き、イメージスケッチ、ホームページ記事の下書き。この冊子の挿絵も生成AIで描いています。
覚えておくこと
生成AIが作るのは「下書き」。正しさの確認と最終判断は、人がします。
05LLM（大規模言語モデル）エルエルエム / Large Language Model
ひとことで

膨大な文章を読んで、言葉のつながりを学んだAI。ChatGPT・Claude・Geminiの中心にあるもの。

たとえると

図書館の本を何万冊も読んだ「物知りで話し上手な人」。次にどんな言葉が来るかを予想するのが、とても上手です。

SpaceClipでは
Claude（Claude Code）、ChatGPT、NotebookLM（中身はGemini）など、ふだん使っている対話型AIはLLMです。
覚えておくこと
話し方が自然でも、中身が正しいとは限りません。「それらしく話す」のが得意な仕組みです。
06モデルModel
ひとことで

学習によって出来上がった、AIの「頭脳」にあたる部分。アプリの中で実際に考えている本体。

たとえると

車の「エンジン」。同じ車体（アプリ）でも、積むエンジン（モデル）によって速さや燃費が変わります。

SpaceClipでは
Claudeの中でも、じっくり考えるOpus、バランスのよいSonnet、速くて軽いHaikuなど、モデルを選べます。
覚えておくこと
「どのアプリか」と「どのモデルか」は別の話。結果が違うときは、モデルも確かめましょう。

07学習（トレーニング）がくしゅう / Training
ひとことで

AIが大量のデータからパターンを身につける工程。モデルを作るときに、開発会社が行う。

たとえると

料理人の「修業時代」。何年もかけてレシピを読み、腕を磨きます。お店を開いてからは、毎日の注文で腕が勝手に上がるわけではありません。

SpaceClipでは
会話の中で教えたことは、その会話の中で参照しているだけ。AIそのものが学習して賢くなったわけではありません。
覚えておくこと
「さっき教えたのに忘れた」のは、学習ではなく“その場の参照”だったから。覚えておいてほしいことは、毎回渡すか、スキルや資料にしておきます。
08推論すいろん / Inference
ひとことで

学習を終えたAIが、質問を受けて答えを出す処理。私たちがAIを使うときは、いつも推論をしている。

たとえると

一人前になった料理人が、お客さんの注文を受けて一皿を作ること。修業（学習）で身につけた腕を、注文（質問）ごとに使います。

SpaceClipでは
「この文章を要約して」と頼んでから、返事が返ってくるまでが推論。待ち時間や利用料金も、ここでかかります。
覚えておくこと
日本語の「推理」とは少し意味が違います。答える前にじっくり考える「推論モデル」と呼ばれるAIもあります。
09プロンプトPrompt
ひとことで

AIに渡す指示や質問の文章。

たとえると

職人さんへの「発注書」。「棚を作って」だけより、寸法・材料・置き場所・納期まで書くほど、思い通りの物が届きます。

SpaceClipでは
×「議事録にして」→ ○「施主向けに、決まったこと・宿題・次回までの確認事項に分けて、A4 1枚で」
覚えておくこと
何を・誰向けに・どんな形で・何に使うか。この4つを伝えると、答えがぐっと良くなります。
10トークンToken
ひとことで

AIが文章を処理するときの、小さな区切りの単位。扱える量や利用料金は、トークンで数える。

たとえると

文章を細かく切った「ブロック」。AIは文章をひと続きではなく、小さなブロックの並びとして読んでいます。

SpaceClipでは
長いPDFを何冊も読ませると、すぐに一度に扱える量や、利用量の上限に届きます。
覚えておくこと
1文字＝1トークンとは限りません。日本語は、おおよそ1文字で1トークン前後が目安です。
11コンテキストContext / 文脈
ひとことで

AIが答えるときに手がかりにする、その場の情報。それまでの会話、添付した資料、前提条件など。

たとえると

打合せ前に渡す「申し送り」。経緯を知らない人にも、背景を伝えてから頼めば話が早く進みます。

SpaceClipでは
「京都市内・準防火地域・木造2階の町家の改修」と前提を書いてから質問すると、法チェックの答えが的確になります。
覚えておくこと
AIは、言われていないことは知りません。前提は省かずに書きましょう。
12コンテキストウィンドウContext Window
ひとことで

AIが一度に覚えておける情報の量の上限。

たとえると

「作業机の広さ」。机に広げられる資料には限りがあり、あふれた分は見えなくなります。

SpaceClipでは
長い会話を続けていると、最初に伝えた条件を忘れたような答えが出ることがあります。そのときは要点をまとめて、新しい会話で始め直します。
覚えておくこと
大事な条件は短くまとめて、最初に（必要なら改めて）伝えます。
13マルチモーダルMultimodal
ひとことで

文章だけでなく、画像・音声・PDF・動画など、複数の種類の情報を扱えること。

たとえると

目と耳と口がそろった人。図面を見て、声を聞いて、言葉で答えられます。

SpaceClipでは
現場写真を見せて「劣化している所を挙げて」と頼む。手描きスケッチの写真から、説明文を起こしてもらう。
覚えておくこと
扱える種類はサービスやモデルによって違います。図面の細かい寸法の読み取りは、まだ間違えやすい分野です。
図でつかむ　AIが答えを出すまで

第2章の言葉を一つの流れにすると、こうなります。良い答えをもらうコツは、左側の「プロンプト」と「コンテキスト」をていねいに渡すこと。机（コンテキストウィンドウ）からあふれないよう、要点をしぼって渡すのも大切です。

×「この資料まとめて」
○「施主への説明用に、要点3つと確認が必要な点に分けて、箇条書きで」
第3章気をつけたいことAIと安心して付き合うための言葉
14ハルシネーションHallucination / 幻覚
ひとことで

事実と違う内容を、もっともらしく答えてしまうこと。

たとえると

知ったかぶりの「自信満々な道案内」。知らない道でも、堂々と案内してしまいます。

SpaceClipでは
存在しない条文番号や告示、実在しない本や事例を、それらしく挙げることがあります。
覚えておくこと
法令・数字・出典は、必ず元の資料（条文・公式サイト）を開いて確かめます。
15バイアスBias / かたより
ひとことで

AIの判断や答えに出る「かたより」。学んだデータのかたよりが、そのまま答えに出る。

たとえると

色付きの眼鏡。悪気はなくても、眼鏡の色で景色の見え方が変わってしまいます。

SpaceClipでは
「理想の住まい」の絵を頼むと、似たような家族像や、洋風の家ばかりが出てくることがあります。
覚えておくこと
立場を変えて聞き直す、複数の案を出させる、と偏りに気づきやすくなります。
16データの学習利用（オプトアウト）追加Opt-out
ひとことで

入力した内容を、AIの会社が次のモデルの学習に使うかどうか。使わせない設定にすることを「オプトアウト」という。

たとえると

預けた書類を「コピーして社内の勉強に使ってよいか」という同意。初めの設定のままだと「使ってよい」になっているサービスもあります。

SpaceClipでは
施主の個人情報、未公開の図面や見積は、会社で認めたサービス以外には入れません。
覚えておくこと
迷ったら入れない。どのサービスなら入れてよいかは、社内のルールで確かめます。
17ガードレールGuardrail
ひとことで

AIが間違った動きや危ない動きをしないように設ける、ルールや制限。

たとえると

山道のガードレール。ふだんは意識しませんが、道からはみ出しそうなときに止めてくれます。

SpaceClipでは
AIにメールの下書きは作らせても、送信のボタンは人が押す。ファイルを消す前には、確認が出るようにしておく。
覚えておくこと
完全には防げません。ガードレールがあっても、運転するのは人です。
18ヒューマン・イン・ザ・ループHuman-in-the-Loop
ひとことで

AIの作業の途中に、人の確認や判断を組み込むこと。

たとえると

図面の「チェックバック」。担当が描いた図面を、出す前に必ず別の人が赤ペンで確認する流れです。

SpaceClipでは
Zoomの文字起こしから議事録を作るとき、「排煙」が「肺炎」になるような誤変換を、人が見て直してから配ります。
覚えておくこと
どこで・誰が確認するかを、先に決めておきます。
SpaceClipでAIを使うときの　5つの約束
  • 1下書きとして受け取るAIの答えは下書き。最後に判断し、責任を持つのは人です。
  • 2元の資料で確かめる法令・数字・固有名詞・出典は、必ず元の資料を開いて確認します。
  • 3大事な情報は入れない施主の個人情報や未公開の図面は、認められたサービスだけに。
  • 4送る・消す・払うは人が押す外に出る操作と、取り消せない操作は、人が確認してから。
  • 5前提をきちんと伝える誰向けに・何に使うか・どんな形で。言わないことはAIは知りません。

第3章の言葉は、どれもこの5つに行き着きます。迷ったら、この約束に戻ってください。

第4章資料を読ませて答えさせる手元の資料をAIに使わせるときの言葉
19ナレッジKnowledge / 知識
ひとことで

仕事に役立つ知識や経験。AIの世界では、答えの参考にさせる資料のことも指す。

たとえると

ベテランの「虎の巻」。マニュアルには書いていない、経験から生まれたコツです。

SpaceClipでは
過去の確認申請での指摘、京都市との協議のやりとり、現場での納まりのコツなど。
覚えておくこと
AIに渡せるのは、書き残された知識だけ。頭の中の経験は、まず文章にします。
20ナレッジベースKnowledge Base
ひとことで

知識を整理して、探して使えるようにまとめた保管庫。

たとえると

よく整理された「資料棚」。見出しが付いていて、誰でも必要な物をすぐに取り出せます。

SpaceClipでは
Obsidianの保管庫（SC_Vault）や、AI部のナレッジのフォルダ。
覚えておくこと
古い情報が混ざると、AIも古い答えを出します。更新と、誰が見られるかの管理が大切です。
21RAG（検索拡張生成）ラグ / Retrieval-Augmented Generation
ひとことで

質問に関係する資料をまず探し出し、その内容をもとにAIが答える仕組み。

たとえると

「持ち込み可」の試験。記憶だけで答えるのではなく、資料をめくって確かめてから答えます。

SpaceClipでは
NotebookLMに法令集や要綱のPDFを入れて、出典付きで答えさせる使い方がこれです。
覚えておくこと
答えの良し悪しは、入れた資料の新しさと、探す精度で決まります。
22グラウンディングGrounding / 根拠づけ
ひとことで

AIの答えを、根拠となる資料や事実に結びつけること。

たとえると

根拠のページに「付せん」を貼って報告してくれる部下。どこに書いてあるかが分かるので、すぐ確かめられます。

SpaceClipでは
「添付の議事録に書いてあることだけで答えて。書いていなければ『記載なし』と答えて」と頼みます。
覚えておくこと
RAGは、グラウンディングのための代表的な方法です。出典が付いていたら、そこを開いて確かめましょう。
23埋め込み（エンベディング）Embedding
ひとことで

文章や画像の「意味」を、数字の並び（地図の上の位置のようなもの）に置き換える技術。

たとえると

言葉を「地図」の上に置くこと。意味の近い言葉ほど、地図の上で近くに集まります。

SpaceClipでは
「休暇」と「休み」が近い意味だとAIが分かるのは、この技術のおかげです。
覚えておくこと
直接さわることはまずありません。次の「セマンティック検索」の土台になる技術です。
24セマンティック検索意味検索 / Semantic Search
ひとことで

言葉が一字一句同じでなくても、意味が近いものを探し出す検索。

たとえると

気の利く「図書館の司書さん」。「雨の日に読みたい本」と頼めば、題名に「雨」が無くてもぴったりの本を出してくれます。

SpaceClipでは
「階段の手すりの決まり」で探して、言い回しの違う条文や、過去の打合せメモも見つかります。
覚えておくこと
言い回しが違っても探せる一方で、品番や型番のような「完全に同じ文字」を探すのは苦手なこともあります。
25ファインチューニングFine-tuning / 追加学習
ひとことで

学習済みのモデルに追加で学習させて、特定の仕事や書き方に合わせること。

たとえると

中途採用の人が受ける「社内研修」。基本ができる人を、うちのやり方に合わせて仕上げます。

SpaceClipでは
自分たちで行うことはまずありません。うちの書式に合わせたいときは、スキル（手順書）や見本を渡す方が手軽です。
覚えておくこと
資料を添付する・スキルを使う、とは別物で、費用も手間も大きい方法です。
図でつかむ　RAG（資料を探してから答える）の流れ

第4章の言葉はつながっています。資料をナレッジベースに整理し、埋め込みとセマンティック検索で関係する所を探し、RAGで答えさせ、出典を示してグラウンディングする。NotebookLMは、この流れをまとめてやってくれる道具です。

第5章AIに仕事を任せるAIが道具を使い、作業まで進めるときの言葉
26AIエージェントAI Agent
ひとことで

目標を伝えると、自分で手順を考え、道具を使いながら作業を進めていくAI。

たとえると

「お使い」を頼める助手。行き先や買う物を自分で調べ、途中で判断しながら用事を済ませてきます。

SpaceClipでは
Claude Codeや、Clipチーム（Tidy＝案件整理、Shiori＝記事の下書き、TOMO＝AIニュース）がこれにあたります。
覚えておくこと
任せる範囲と、人が確認する場面（送信・削除・支払いなど）を、先に決めておきます。
27ツール呼び出しTool Use
ひとことで

AIが、検索・計算・ファイル操作・カレンダーなど、外の道具を使うこと。

たとえると

「道具箱」を持たせること。手ぶらでは無理な作業も、電卓やメジャーがあればできます。

SpaceClipでは
天気予報を調べて朝のまとめを作る、カレンダーから今日の予定を読む、面積を計算する。
覚えておくこと
どの道具を使えるか、何をしてよいかは、設定で決まります。
28APIエーピーアイ / Application Programming Interface
ひとことで

ソフトウェア同士が、機能やデータをやりとりするための決まった「窓口」。

たとえると

レストランの「ウェイター」。客は厨房に入らず、決まった形で注文し、料理を受け取ります。

SpaceClipでは
自作のアプリからAIに文章を送り、要約を受け取る。使った量に応じて料金がかかります。
覚えておくこと
APIキーは「合鍵」。人に見せたり、メールやチャットに貼ったりしません。
29MCP（コネクタ）追加エムシーピー / Model Context Protocol
ひとことで

AIを、外のサービス（Gmail・カレンダー・ドライブなど）につなぐための共通の規格。Claudeでは「コネクタ」と呼ぶ。

たとえると

電源の「共通コンセント」。差し込み口の形がそろっているので、いろいろな機器をすぐにつなげます。

SpaceClipでは
ClaudeからGmailの下書きを作る、Googleカレンダーの予定を読む、Canvaのデザインを開く。
覚えておくこと
つないだサービスの中身は、AIから見えるようになります。必要なものだけをつなぎます。
30スキル追加Skill / 手順書
ひとことで

AIに渡しておく「仕事の手順書」。決まった仕事を、毎回同じやり方・同じ品質でこなせるようにする。

たとえると

事務所の「業務マニュアル」。新人でも、マニュアルを見れば同じ書式で書類が作れます。

SpaceClipでは

33バイブコーディングVibe Coding
ひとことで

腕のいい大工さんに、その場で見ながら「ここに棚がほしい、もう少し低く」と伝えて作ってもらうこと。

覚えておくこと
